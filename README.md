# منصة خبير — النسخة التجريبية

مكتب حقوقي رقمي: العميل يتعامل مع «خبير» مباشرة، وفريق المحامين والإدارة يعملون من الداخل.

- **الموقع:** https://iba9ma.github.io/khabeer/
- ثلاث تجارب: العميل، المحامي، الإدارة (بيانات تجريبية محفوظة في المتصفح فقط).
- قابل للتثبيت على الجوال كتطبيق (PWA).

## الملفات
- `khabeer.html` — مصدر المنصة.
- `build-site.ps1` — يبني الموقع في مجلد `site/` (ثم يُنسخ إلى `docs/`).
- `docs/` — الموقع المنشور على GitHub Pages.
